# Taller de grafos con ordenamiento

Este proyecto es un programa de consola hecho en Java para representar rutas entre varias ciudades de Colombia como un grafo. Cada ruta tiene una distancia en kilómetros, y desde el menú se pueden consultar y ordenar las conexiones.

También permite encontrar caminos de menor distancia con los algoritmos de Dijkstra y Floyd-Warshall, y recorrer las ciudades con BFS y DFS. El proyecto incluye pruebas automáticas para comprobar que los algoritmos y las rutas funcionen como se espera.

## Cómo ejecutar

Necesitas tener instalado Java. Desde esta carpeta, compila los archivos y ejecuta el programa:

```text
javac *.java
java Main
```

Para ejecutar las pruebas:

```text
java Pruebas
```
